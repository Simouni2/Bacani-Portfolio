## 💡 Tips & Best Practices

### Development
- Run `npm run dev` to start development server
- Use DevTools (F12) to inspect and debug
- Check TypeScript errors before building

### Customization
- Keep components in `src/components/`
- Edit content in component files
- Don't modify build configuration unless necessary
- Use Tailwind classes for styling

### Deployment
- Build locally first: `npm run build`
- Test production build: `npm start`
- Deploy to Vercel for best results
- Follow DEPLOYMENT.md step-by-step

### Performance
- Portfolio is already optimized
- Images are compressed
- Code is minified on build
- Animations are hardware-accelerated

## 🔧 Troubleshooting

### Port 3000 in use?
→ Runs on 3001 instead (automatic)

### Build errors?
→ Clear cache: `rm -r .next` then `npm run build`

### Module not found?
→ Reinstall: `npm install`

### Animations lag?
→ Check browser performance (F12 → Performance)

👉 See [QUICKSTART.md](QUICKSTART.md) for more help
